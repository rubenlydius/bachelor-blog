Regular paragraphs are plain markdown. **Bold**, _italic_ and [links](https://astro.build) work as usual.
Components (`Figure`, `Breakout`, `ImageRow`, `TwoColumn`) are available without importing them;
only images need an import so Astro can optimize them.
